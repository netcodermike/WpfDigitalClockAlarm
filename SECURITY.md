# Security reporting

Do not include personal task files, credentials, or sensitive data in public issues. For a sensitive vulnerability, use GitHub private vulnerability reporting if enabled; otherwise open a public issue requesting a private reporting channel without disclosing exploit details.

Task JSON and its backup are stored in plaintext under the current Windows user's local application data. The application has no network synchronization, update mechanism, or authentication layer. Use the latest reviewed source and supported .NET servicing updates.
